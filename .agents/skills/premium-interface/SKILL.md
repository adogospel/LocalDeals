# Premium Interface

Create interfaces that feel polished, modern, professional and intentionally designed.

Adapt the visual identity to the project instead of applying the exact same design everywhere.

## Design direction

Prefer:

- clean and premium visual hierarchy
- modern typography
- generous but controlled spacing
- strong section composition
- subtle depth
- restrained shadows
- polished cards
- consistent border radii
- high-quality icons
- elegant visual rhythm
- clear primary actions
- excellent readability

Avoid generic AI-looking interfaces.

Do not overload the interface with:
- excessive gradients
- excessive glassmorphism
- unnecessary rounded cards
- random decorative effects
- too many colors
- animations without purpose

## Responsive design

Always design mobile-first.

The interface must work well on:

- small mobile screens
- large phones
- tablets
- laptops
- desktop screens

Do not simply shrink the desktop layout.

Reconsider:
- navigation
- spacing
- typography
- grids
- cards
- tables
- CTA placement
- content priority

for smaller screens.

## UX

Think about the complete user experience.

Include appropriate:

- loading states
- empty states
- error states
- hover states
- focus states
- disabled states
- confirmation feedback
- validation feedback

Important actions must be easy to find.

Avoid unnecessary clicks.

## Animations

Use animations to improve perceived quality and UX.

Prefer:

- subtle entrance animations
- smooth section reveals
- tasteful scroll animations
- hover micro-interactions
- button feedback
- card transitions
- smooth modal/dropdown transitions

When appropriate, use:
- GSAP
- Framer Motion
- CSS transitions

Animations should remain fluid and restrained.

Do not animate everything.

Prioritize performance.

## Frontend architecture

Before creating a component:

1. Inspect the existing project structure.
2. Reuse existing components when possible.
3. Respect the current design system.
4. Avoid duplicating components.
5. Keep components maintainable and reasonably small.
6. Separate UI from complex business logic when appropriate.

Do not refactor unrelated parts of the project.

## Visual consistency

Maintain consistency across:

- typography
- spacing
- colors
- borders
- radii
- shadows
- icons
- buttons
- cards
- inputs

Use existing design tokens when available.

If no design system exists, establish a small coherent one.

## Marketing websites

For landing pages and showcase websites:

- create a strong hero section
- establish clear value proposition
- use strong but non-aggressive CTAs
- guide the visitor naturally through the page
- use visual storytelling
- establish trust
- highlight important benefits
- maintain good content rhythm
- optimize for conversion without harassing the visitor

## Dashboards and applications

For application interfaces:

Prioritize:
- clarity
- usability
- information hierarchy
- quick access to common actions
- good data density
- responsive tables or mobile alternatives
- understandable navigation

The interface must remain professional even with large amounts of data.

## Final quality check

Before considering the UI complete, check:

- responsive behavior
- spacing consistency
- alignment
- text hierarchy
- mobile navigation
- overflow
- visual states
- accessibility basics
- animation smoothness
- unnecessary duplication
